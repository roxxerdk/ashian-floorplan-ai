# Ashian – Ask Your Floor Plan

An AI-powered assistant that answers natural-language questions about architectural floor plans using structured, extracted data.

## Project Objectives

- Extract rooms, doors, windows and walls.
- Process floor-plan images and segmentation masks.
- Store extracted information in SQLite.
- Answer natural-language questions using database queries.
- Display answers with supporting evidence.
- Evaluate answer accuracy and grounding.

## Technology Stack

- Python 3.11
- OpenCV
- NumPy
- SQLite
- Streamlit
- LLM with tool calling

## Project Structure

- data/: Dataset storage
- src/: Application source code
- outputs/: Generated visualizations
- tests/: Automated tests
